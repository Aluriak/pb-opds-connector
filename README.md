# PocketBook OPDS Connector

An OPDS connector for PocketBook ebook readers. Manage connections to Archive.org, Calibre, Manybooks, Flibusta and more.

**Features**

* Connecting to OPDS interfaces (authentication not supported yet)
* **Default set of available OPDS sources:**
  * Flibusta
  * ManyBooks
  * Gutenberg
  * Standard Ebooks
* **Download the format you want:** Select the format you want, from all formats offered, showing a progress bar while downloading.

## Compatibility

Only firmware 6.x is supported. Anything older is not supported and will not work.

| Firmware | Devices | Status |
|---|---|---|
| 6.11 | Era Lite (PB710) | ✅ Tested |
| 6.x | Other Allwinner B288 models: Era, InkPad 4, InkPad Lite, Verse, Verse Pro, Touch HD 3 | ❔ Untested, expected to work |
| 6.x | Allwinner B300 models: Era Color, Verse Pro Color, InkPad Color 2/3, InkPad X Pro | ❔ Untested |
| 6.11 | Rockchip RK3566 models: Verta, Verta Color, InkPad One, PocketBook Q | ❔ Untested, expected to work |

If you have a model, that is not tested yet, it would help a lot, if you can try out the connector.
After that please open an issue and report your findings, telling the model name and firmware version.
